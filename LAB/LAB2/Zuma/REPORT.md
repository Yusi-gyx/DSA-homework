2. **原因**：`play` 在消除后无条件调用 `play(left - 1)`。

   初始 `AA`，在 0 号位置插入 `A` 得到 `AAA`，整段从下标 0 开始消除，`left == 0`。

**测例**

```text
AA
1
```

### 代码 03

1. **最严重错误类型**：Time Limit Exceeded。
2. **原因**：`std::string::insert/erase` 每次要移动 $O(n)$ 个字符，m 次操作总复杂度 $O(nm)$；
   n = m = $5×10^5$ 时约搬运 $3.75×10^{11}$ 字节，超过了 1.5 s 时限。
3. **发现方法**：复杂度分析 + 计时，本地 -O2 跑最大规模约 5.0 s。
4. **测例构造**：初始串取 500000 个字符的 `AABB` 重复；500000 次操作全部在 0 号位置交替插入 `C`、`D`，
   与相邻珠子都不同色，不会发生消除，于是每次插入都要把整串右移一位。

**测例**

初始串 $s=(\text{AABB})^{125000}$（长度 $5\times 10^5$），操作数 $m=5\times 10^5$，第 $i$ 次操作（$i=0,1,\dots,m-1$）为

$$
\text{pos}_i=0,\qquad c_i=\begin{cases}C, & i\text{ 为偶数}\\ D, & i\text{ 为奇数}\end{cases}
$$

$m$ 行 `0 C`、`0 D` 交替出现。期望输出为 $(\text{DC})^{250000}(\text{AABB})^{125000}$。

**测例**

```text

1

```

### 代码 07

1. **最严重错误类型**：Runtime Error。
2. **原因**：左扫描跨空块时只跳一次（`if` 应为 `while`）。若跳过去的那块长度为 0，
   `l.second` 仍为 -1，下一次 `get(l)` 会读 `p[l.first][-1]`，即上一行的最后一字节。
   这个字节若恰好等于待消除颜色，消除区间就被错误放大；执行时
   `plen[l.first] = l.second + 1` 得到 -1，赋给 `size_t` 变成极大值，`p2a()` 中 `memcpy` 发生崩溃。
3. **发现方法**：随机对拍未命中错误；询问大模型后使用中间变量 + 定向构造找出错误
   `plen[0] = SIZE_MAX`。
4. **测例构造**：初始 `AABB`×1024；先在 0 号位置插入 2048 个字符（`B,B,A,A` 循环），
   把 0 号块撑到 4096，最后一次插入在 `p[0][4095]` 留下 `B` 并触发重分块；
   再在 3070 号位置插入 `B`，长连锁把整串消到只剩末尾 `BB`，得到 `plen = {0, 0, 2}`；
   最后在 0 号位置插入 `B`，左扫描进入空块 1 时读到 `p[1][-1] = p[0][4095] = 'B'`，触发下溢。

**测例**

初始串 $s=(\text{AABB})^{1024}$（长度 $4096$），操作数 $m=2050$：

- 第 $i$ 次操作（$i=0,1,\dots,2047$）：$\text{pos}_i=0$，$c_i=(\text{BBAA})[\,i \bmod 4\,]$；
- 第 $2048$ 次操作：`3070 B`；
- 第 $2049$ 次操作：`0 B`。

即前 2048 行是 `0 B`、`0 B`、`0 A`、`0 A` 循环，之后依次跟着 `3070 B` 和 `0 B`。

### 代码 09

1. **最严重错误类型**：Runtime Error。
2. **原因**：其它版本都有 `if (l.first == r.first)` 的“块内消除”分支，09 删掉了它，
   块内消除使用跨块逻辑：先 `plen[l.first] = l.second + 1` 把块截断，
   再用已变小的 `plen` 算 `len = plen[r.first] - r.second`，结果为负；
   负的 `int` 赋给 `size_t` 的 `plen` 后下溢，`p2a()` 用它调用 `memcpy` 时崩溃。
3. **发现方法**：对拍 + gdb调试。
4. **测例构造**：初始 `ABBA`，在 2 号位置插入 `B` 得到 `ABBBA`；消除中间 `BBB` 时 `l = (0,0)`、`r = (0,4)`，`plen[0]` 先被改成 1，再算出 `len = 1 - 4 = -3`，写入 `size_t` 后下溢成极大值，`p2a()` 调用 `memcpy` 时崩溃。

**测例**

```text
ABBA
1
2 B
```
