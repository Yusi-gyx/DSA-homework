9. 代码9
    1. 最严重错误类型：Runtime Error
    2. 出现错误的原因
        删掉了 if (l.first == r.first)（同块内消除）这一分支，单块内消除也走跨块分支。当消除块位于同一块内时，先执行 plen[l.first] = l.second + 1 截断该块，又在同一块上执行右分支、用已被截断的长度计算 len = plen[r.first] - r.second（常为负），赋给 size_t 类型的 plen 后下溢成极大值，后续访问越界 → 崩溃。
    3. 发现错误的方法
        对拍。异常退出（rc=134）。
    4. 测例的构造
        单块中间消除：

        ```text
        ABBA
        1
        2 B
        ```

        插入后 "ABBBA"，消中间 "BBB" 留下 "AA"；09 因 plen 被错误覆盖（下溢）而崩溃。

10. 代码10
    1. 最严重错误类型：Wrong Answer
    2. 出现错误的原因
        跨块消除时，清零中间块的循环 for (int i = l.first; i < r.first; i++) 起始值应为 l.first + 1，写成了 l.first，把左边界块（保存着消除块左侧保留下来的珠子）也清零，丢失左侧珠子。当消除块触及块边界（即便只有一个块、触到序列头/尾）时即触发。
    3. 发现错误的方法
        对拍。与 base.cpp 用随机测例比对，输出不同。
    4. 测例的构造
        先让消除块触及序列末端，再追加一次操作使错误显现：

        ```text
        BAA
        2
        3 A
        1 C
        ```

        第一次插入 A 消掉 "AAA" 后应剩 "B"；此时 plen[0] 已被错误清零，只因 a 中还残留着初始串而暂时看不出错误。第二次插入 C 后正确结果应为 "BC"，但 plen 已被破坏，10 输出 "BA"。
